WALLSETS / ЖИВЫЕ ОБОИ

Запуск: Wallsets.exe. Оба исходных набора включены по умолчанию.
В списке слева отметьте галочкой один или несколько наборов.
Набор выбирается только галочкой, отдельной подсветки строки нет.

Свои наборы
Откройте папку «Наборы» и создайте внутри папку с любым названием.
Положите в неё видео и фотографии. Приложение обновит список автоматически.
Можно также нажать кнопку создания набора. Вложенные папки поддерживаются.
Поддерживаются распространённые форматы MP4, MKV, WebM, MOV, AVI, GIF,
JPG, PNG, WebP, BMP, TIFF, AVIF и другие поддерживаемые движком mpv кодеки.
Повреждённые и неподдерживаемые файлы пропускаются, ошибка записывается
в errors.log. Не каждый существующий кодек гарантированно доступен.

Очередь
Справа показаны превью обоев, порядок — слева направо и сверху вниз.
Номер на превью — место в очереди.
«Общая очередь»: можно отметить несколько наборов, их обои идут одной
очередью. По умолчанию наборы идут друг за другом; «Перемешать»
перемешивает обои всех отмеченных наборов между собой.
«Выбранный набор»: можно отметить только один набор, новая галочка
снимает предыдущую.
«По умолчанию»: естественный порядок имён файлов.
«Вручную»: возьмите превью мышью и перетащите: остальные превью
раздвигаются на лету и показывают, куда оно встанет. Также работают
кнопки «Раньше/Позже в очереди».
«Перемешать»: случайный порядок, который сохраняется между запусками.
Кнопка перемешивания создаёт новый случайный порядок.
Размер превью: мелкие, средние, крупные, очень крупные (или Ctrl +
колесо мыши). В развёрнутом окне в ряд помещается 12, 9, 6 и 4 превью.
Превью видео и фото берутся у Windows; для форматов, у которых Windows
не делает эскизов (например HEVC, AV1, WebM, AVIF без доп. кодеков),
кадр сохраняет встроенный mpv. Превью кэшируются в папке .cache.
Двойной щелчок по превью сразу устанавливает его на рабочий стол.

Время и пауза
Интервал смены задаётся в секундах: от 5 секунд до 24 часов.
Каждое видео зациклено до следующей смены; длительность ролика не важна.
Кнопка паузы останавливает видео, но таймер смены продолжает работать.
После смены новый ролик тоже будет на паузе, пока вы её не снимете.
Фотографии показываются неподвижно до следующей смены.
Изображение заполняет экран с обрезкой краёв.

Звук
Кнопка с динамиком рядом с кнопками воспроизведения включает режим
«Проигрывать с музыкой»: играет звуковая дорожка текущих обоев.
По умолчанию звук выключен, звуковое устройство при этом не занято.
Ползунок рядом задаёт громкость музыки обоев от 0 до 100%. Это
собственная громкость Wallsets: она не меняет громкость Windows и
других программ (общая громкость Windows по-прежнему действует сверху).
В микшере громкости Windows обои видны как «Wallsets».
Пауза (ручная или автопауза) останавливает и музыку.

Управление вне окна
Ctrl+Alt+P: пауза / продолжить видео.
Ctrl+Alt+N: следующие обои.
Ctrl+Alt+B: предыдущие обои.
Значок Wallsets в системном трее: открыть окно, пауза, предыдущие,
следующие, проигрывать с музыкой, выход.
Двойной щелчок по значку открывает окно.
«Мини-пульт» включает маленькое перемещаемое окно с кнопками
«предыдущие», «пауза» и «следующие».
Закрытие главного окна крестиком оставляет обои работать в трее.
Горячие клавиши могут быть недоступны, если их заняла другая программа.

Полное отключение
«Отключить и выйти» завершает приложение и его проигрыватель.
На рабочем столе также есть отдельный ярлык отключения.
Stop-Wallsets.ps1 завершает только процессы этой установки даже при сбое.
Исходные настройки обоев Windows не меняются: после выхода обычный фон
снова виден. Фоновые службы и задания автозапуска не устанавливаются.
Обои при старте Windows автоматически не включаются.

Ресурсы
Аппаратное декодирование D3D11, быстрый профиль масштабирования,
один проигрыватель и приоритет ниже обычного. Браузер не используется.
Автопауза ставит проигрыватель на паузу: декодирование и отрисовка
останавливаются, на экране остаётся последний кадр, нагрузка на CPU и
GPU падает почти до нуля. Память (около 250 МБ) при паузе не
освобождается. Таймер смены обоев продолжает работать.
«Пауза за развёрнутым окном»: раз в секунду проверяется, закрывает ли
развёрнутое или полноэкранное окно рабочий стол основного монитора.
Щелчок по панели задач или по окну Wallsets паузу не снимает: тогда
решает окно, лежащее под ними.
«Пауза от батареи»: пауза, пока ноутбук работает без зарядки.
При блокировке компьютера или выключенном дисплее пауза включается
всегда. На CPU/GPU влияет разрешение, кодек и частота кадров файла.
Приложение использует основной монитор Windows.
Если Проводник Windows перезапустился, обои подключаются заново сами.

Файлы установки
Wallsets.exe, папка engine и папка «Наборы» должны оставаться рядом.
Папки «Первый набор» и «Второй набор» являются ссылками на исходные
папки «Видео» и «Видео2»: 42 ролика не дублировались и не перемещались.
Изменения содержимого этих двух наборов меняют исходные папки.
Не перемещайте исходные папки без обновления ссылок.
Работает в Windows 10 и Windows 11 (x64). Нужна установленная
среда .NET Desktop Runtime 10 (x64); если её нет, Windows при запуске
предложит скачать её с сайта Microsoft.
Значки кнопок: в Windows 11 шрифт Segoe Fluent Icons, в Windows 10
Segoe MDL2 Assets.
Настройки хранятся в settings.json рядом с программой.

Командная строка
Wallsets.exe --tray      запуск в трее
Wallsets.exe --show      открыть окно работающего приложения
Wallsets.exe --pause     переключить паузу
Wallsets.exe --next      следующие обои
Wallsets.exe --previous  предыдущие обои
Wallsets.exe --stop      полное отключение
Wallsets.exe --rescan    перечитать папки
Wallsets.exe --status    записать состояние в status.json

Исходный код приложения находится в соседней папке src.
Сборка: dotnet publish src/Wallsets.csproj -c Release -r win-x64
        --self-contained false -p:PublishSingleFile=true -o Wallsets
Сборка не в Windows: добавьте -p:EnableWindowsTargeting=true
