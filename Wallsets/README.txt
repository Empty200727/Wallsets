WALLSETS / ЖИВЫЕ ОБОИ

Запуск: Wallsets.exe. Оба исходных набора включены по умолчанию.
В списке слева отметьте первый, второй или несколько наборов.
Нажатие «Первые два» выбирает только исходные два набора.

Свои наборы
Откройте папку «Наборы» и создайте внутри папку с любым названием.
Положите в неё видео и фотографии. Приложение обновит список автоматически.
Можно также нажать кнопку создания набора. Вложенные папки поддерживаются.
Поддерживаются распространённые форматы MP4, MKV, WebM, MOV, AVI, GIF,
JPG, PNG, WebP, BMP, TIFF, AVIF и другие поддерживаемые движком mpv кодеки.
Повреждённые и неподдерживаемые файлы пропускаются, ошибка записывается
в errors.log. Не каждый существующий кодек гарантированно доступен.

Очередь
Нажмите название набора слева для редактирования его очереди справа.
«По умолчанию»: естественный порядок имён файлов.
«Вручную»: перетаскивайте строки мышью или используйте стрелки вверх/вниз.
«Перемешать»: случайный порядок, который сохраняется между запусками.
Кнопка перемешивания создаёт новый случайный порядок.
При выборе нескольких наборов их очереди объединяются последовательно.
Двойной щелчок по файлу сразу устанавливает его на рабочий стол.

Время и пауза
Интервал смены задаётся в секундах: от 5 секунд до 24 часов.
Каждое видео зациклено до следующей смены; длительность ролика не важна.
Кнопка паузы останавливает видео, но таймер смены продолжает работать.
После смены новый ролик тоже будет на паузе, пока вы её не снимете.
Фотографии показываются неподвижно до следующей смены.
Воспроизведение без звука. Изображение заполняет экран с обрезкой краёв.

Управление вне окна
Ctrl+Alt+P: пауза / продолжить видео.
Ctrl+Alt+N: следующие обои.
Значок Wallsets в системном трее: открыть окно, пауза, следующие, выход.
Двойной щелчок по значку открывает окно.
«Мини-пульт» включает маленькое перемещаемое окно с двумя кнопками.
Закрытие главного окна крестиком оставляет обои работать в трее.
Горячие клавиши могут быть недоступны, если их заняла другая программа.

Полное отключение
«Отключить и выйти» завершает приложение и его проигрыватель.
На рабочем столе также есть отдельный ярлык отключения.
Stop-Wallsets.ps1 завершает только процессы этой установки даже при сбое.
Исходные настройки обоев Windows не меняются: после выхода обычный фон
снова виден. Фоновые службы и задания автозапуска не устанавливаются.
Обои при старте Windows автоматически не включаются.

Ресурсы
Аппаратное декодирование D3D11, быстрый профиль масштабирования,
один проигрыватель и приоритет ниже обычного. Браузер не используется.
За развёрнутым окном, при блокировке или выключенном дисплее включается
автопауза. Настройка паузы от батареи доступна отдельно.
На CPU/GPU влияет разрешение, кодек и частота кадров конкретного файла.
Приложение использует основной монитор Windows.

Файлы установки
Wallsets.exe, папка engine и папка «Наборы» должны оставаться рядом.
Папки «Первый набор» и «Второй набор» являются ссылками на исходные
папки «Видео» и «Видео2»: 42 ролика не дублировались и не перемещались.
Изменения содержимого этих двух наборов меняют исходные папки.
Не перемещайте исходные папки без обновления ссылок.
Для запуска используется установленная на этом ноутбуке .NET Desktop 10.
Настройки хранятся в settings.json рядом с программой.

Командная строка
Wallsets.exe --tray      запуск в трее
Wallsets.exe --show      открыть окно работающего приложения
Wallsets.exe --pause     переключить паузу
Wallsets.exe --next      следующие обои
Wallsets.exe --stop      полное отключение
Wallsets.exe --rescan    перечитать папки
Wallsets.exe --status    записать состояние в status.json

Исходный код приложения находится в соседней папке src.
Сборка: dotnet publish src/Wallsets.csproj -c Release -r win-x64
        --self-contained false -p:PublishSingleFile=true -o Wallsets
